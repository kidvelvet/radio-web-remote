Radio Remote: device setup

Sign in

Why this step

This server uses HTTPS with a certificate from its own local certificate authority (CA). Browsers only allow the microphone on pages they trust, so each device needs the CA installed once. You only download the public certificate; no private key leaves the server.

Download the CA certificate

If the download fails, this server may be using a certificate from your own CA or VPN provider instead, and no install is needed.

Install it

iPhone and iPad (Safari)
  1. Open this page in Safari and tap Download the CA certificate. Allow the download.
  2. Open Settings. Tap Profile Downloaded near the top (or General > VPN & Device Management), then Install.
  3. Required second step: Settings > General > About > Certificate Trust Settings, and under Enable full trust for root certificates, turn on radio-web-remote local CA. Apple does not trust a downloaded certificate for HTTPS until you do this.
  4. Return to Safari and open the address of this server again.
macOS
  1. Download the certificate and double-click it. Keychain Access opens; add it to the login keychain.
  2. Find radio-web-remote local CA, double-click it, open Trust, and set When using this certificate to Always Trust. Close the window and enter your password.
  3. Safari and Chrome use this. Firefox keeps its own list: see Firefox below.
Windows
  1. Download the certificate and double-click it, then Install Certificate.
  2. Choose Current User, then Place all certificates in the following store, Browse, Trusted Root Certification Authorities. Finish and accept the warning.
  3. Edge and Chrome use this. Restart the browser.
Android
  1. Download the certificate.
  2. Open Settings and search for CA certificate (often under Security > Encryption & credentials > Install a certificate > CA certificate). Choose the downloaded file.
Linux
  1. Chrome and Chromium: Settings > Privacy and security > Security > Manage certificates > Authorities > Import, and tick Trust this certificate for identifying websites.
  2. System-wide (Debian, Ubuntu, Raspberry Pi OS): copy it to /usr/local/share/ca-certificates/radio-web-remote.crt and run sudo update-ca-certificates.
Firefox (any desktop system)
  1. Settings > Privacy & Security > Certificates > View Certificates > Authorities > Import.
  2. Tick Trust this CA to identify websites.

Then

Sign in. Ask your club admin for an account; accounts are created on the server, not here.

Every operator must hold a license with privileges for the band and mode in use, and is the control operator while transmitting. The rules of the country where the radio is located apply.
